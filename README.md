## About me

I'm an iOS developer at the Apple Developer Academy | Mackenzie and a Computer Engineering student at Universidade Presbiteriana Mackenzie. I build native apps with Swift and SwiftUI and take them all the way to the App Store: design, code, tests, CI/CD, release and support.

My final project at the Academy, **Braider**, is live on the App Store: an app for hair braiders to run their bookings, with a booking page of their own for their clients. I built it with Leonardo Cruz, from the first sketch to the App Store review, including the backend and the website.

I care about clean architecture (MVVM), unit tests for the logic I write, and documentation that lets anyone run the project.
